 2. FEATURES IMPLEMENTED
════════════════════════════════════════════════════════════════════════════════

✅ DOUBLE BUFFERING SYSTEM
   • Two 1024-byte buffers for efficient I/O
   • Forward pointer for current position
   • Lexeme begin pointer for token start
   • Automatic buffer switching and reloading
   • Seamless EOF detection

✅ POSITION TRACKING
   • Line number tracking (1-based indexing)
   • Column number tracking (1-based indexing)
   • Proper handling across newlines
   • Accurate error reporting with line/col information

   • Punctuation: (, ), [, ], ;, :, ,, .
   • Comments: { ... }

✅ WHITESPACE & COMMENT HANDLING
   • Automatic space/tab skipping

 10. API REFERENCE
════════════════════════════════════════════════════════════════════════════════

SCANNER CLASS:
  Scanner(source_file: str)
    Initialize scanner with source file path
  
  get_next_token() -> Token
    Get the next token from the source
  
  scan() -> List[Token]
    Scan entire file and return all tokens
  
  get_errors() -> List[str]
    Get list of errors encountered
  
  close()
    Close the source file

TOKEN CLASS:
  Token(token_type: str, lexeme: str, line: int, column: int)
    Create a token
  
  to_tuple() -> Tuple
    Get token as tuple
  
  to_dict() -> Dict
    Get token as dictionary
  
  Properties:
    token_type   - Type of token
    lexeme       - Text of token
    line         - Line number
    column       - Column number

TOKEN TYPES (35+):
  KEYWORD_*      - Keywords (PROGRAM, VAR, INTEGER, etc.)
  ID             - Identifiers
  NUMBER         - Numbers
  PLUS, MINUS, MULTIPLY, DIVIDE, EQ, NEQ, LT, LE, GT, GE
  ASSIGN, DOUBLE_DOT
  LPAREN, RPAREN, LBRACKET, RBRACKET
  SEMICOLON, COLON, COMMA, DOT
  EOF            - End of file

class Parser:
    def __init__(self, source_file):
        self.scanner = Scanner(source_file)
        self.current_token = self.scanner.get_next_token()
    
    def advance(self):
        self.current_token = self.scanner.get_next_token()
    
    def parse(self):
        # Parser uses tokens from lexer
        self.advance()
        # ... parsing logic ...
